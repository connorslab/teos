# Native XBT LND backend

This directory contains the full native LND client and tower source.
Use the combined [build guide](../docs/BUILD.md), [tower setup](../docs/TOWER.md),
and [client guide](../docs/CLIENTS.md). Only the XBT-aware Knots backend is supported
by this distribution. Stock Bitcoin, btcd and Neutrino backend support described
in upstream material does not apply to this fork.

The [upstream README](README.upstream.md) is retained for attribution and background.
See [LICENSE](LICENSE).
